# GP26 Shooting ― 前期総まとめ課題【ルートC】

バンタンゲームアカデミー 2026年度 ゲームプログラマー専攻1年 / Unity・C#

このプロジェクトは、**前期総まとめ課題のルートC（サポートルート）** 用の穴埋めプロジェクトです。
スクリプトを付けて数字を入れるだけで、3Dシューティングが1本完成します。

---

## まず読むもの

### → [手順書.md](手順書.md)

STEP 0 から順番に進めれば完成します。**最初に Play しても何も起きませんが、それが正常です。**

---

## 動作環境

> ### ⚠ Unity 6000.3 が必要です
> **これより古いバージョンでは開けません。** Unity Hub で 6000.3 系が入っているか、
> 始める前に確認してください（インストールに時間がかかります）。

| 項目 | 内容 |
|---|---|
| Unity | **6000.3 系**（Unity 6） |
| レンダリング | URP |
| 開くシーン | `Assets/Scenes/GameScene.unity` |
| 追加パッケージ | なし |

> **Active Input Handling** が `Both` になっている必要があります。
> もし `Input.GetKey` でエラーが出たら、Edit → Project Settings → Player → Active Input Handling を `Both` にしてください。

---

## 操作

| キー | 動作 |
|---|---|
| W A S D | 押した方向を向いて進む |
| スペース | 弾を撃つ |

奥にいるボスを倒すと、一番奥のゴールが光ります。ゴールに触れるとクリアです。
